# Шашки ИИ

Русские шашки 8×8 для Android с ИИ, который **учится на самом телефоне** — без интернета и облака
(в манифесте нет разрешения `INTERNET`).

## Как учится ИИ

Обучение с подкреплением, **без поколений и популяций**: одна нейросеть, которая правится после каждого хода.

- **Оценка позиции** — небольшая сеть (128 разреженных входов → 48 → 24 → tanh) + прямая линейная связь.
  Всегда смотрит на доску глазами того, чей ход.
- **Выбор хода** — альфа-бета поиск на 3 хода (при игре с человеком до 10) поверх оценки сети,
  с продолжением цепочек обязательных взятий.
- **Обучение** — TD-leaf(λ): значение листа главного варианта подтягивается к значению следующей позиции;
  следы приемлемости (λ = 0.7) распространяют урок на предыдущие ходы; в конце партии целью становится
  настоящий результат (+1 / 0 / −1). Редкие случайные ходы (ε = 8%) дают исследование.
- **Источники опыта**: партии ИИ с самим собой (кнопка «Обучение ИИ», работает в фоне как служба
  переднего плана) и **каждая партия против человека** — ИИ разбирает её после финала.
- **Измерение силы**: каждые 500 партий ИИ играет 24 партии против «подсчёта шашек» с тем же поиском.
  50 % — на уровне обычного подсчёта материала, выше — выучил позиционную игру.

Сеть стартует с крошечной подсказки «больше шашек — лучше» (веса остаются обучаемыми), чтобы не играть
совсем случайно в первой же партии. Режим «с нуля» (`materialPrior = false`) тоже работает — см. ниже.

### Что измерено на JVM (60 партий против подсчёта материала, глубина 4, цвета чередуются)

| старт | 0 партий | 5 000 | 10 000 | 15 000 |
|---|---|---|---|---|
| с нуля, α = 0.01 | 0 % | 65 % | 73 % | 74 % |
| с подсказкой, α = 0.003 | 65 % | 63 % | 75 % | 62 % |

Против случайного игрока обе версии выигрывают 100 % уже после 500 партий. Разброс между замерами заметный
(±6 %): это не «шахматный мастер», а честно обучающаяся сеть; на телефоне темп зависит от процессора.

## Структура

- `engine/` — чистый Kotlin/JVM, без зависимостей от Android: правила (`Board.kt`), сеть (`Network.kt`),
  поиск (`Search.kt`), TD-обучение и арена (`Learning.kt`), ввод ходов человеком (`HumanGame.kt`).
  Правила сверены с независимой реализацией: идентичные perft до глубины 6 и 15 000 случайных позиций.
- `app/` — Android: `Brain` (сеть на диске + фоновое обучение), `TrainingService`, `BoardView`, экраны.

## Сборка

```bash
./gradlew :engine:test                 # тесты ядра (нужна только JDK 17+)
./gradlew :app:assembleDebug           # APK (нужен Android SDK: ANDROID_HOME или local.properties)
```

Модуль `:app` подключается только если найден Android SDK. minSdk 26, targetSdk 35.
